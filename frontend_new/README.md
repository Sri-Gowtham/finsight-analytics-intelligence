# FinSight: AI Financial Intelligence

Build a production-ready, enterprise-grade Next.js 14 (App Router) application named FinSight, an AI-powered B2B Financial Intelligence Platform for financial consultancy and advisory firms covering NSE-listed Indian banks, using TypeScript, Tailwind CSS, shadcn/ui, React Query, Recharts, lucide-react, React Hook Form, Zod, and mock APIs with localStorage persistence, following a premium Emerald fintech design system (Emerald #0F9D58, Royal Blue AI accent #2563EB, Gold CFO accent #D6B25E, clean Truba Bank–style UI, responsive card-based layout, rounded corners, subtle shadows, generous whitespace, and reusable components), with a public marketing landing page, admin-provisioned authentication (no signup), shared Sidebar, Topbar, Auth Context and RoleGuard, and three fully integrated roles—Analyst, CFO, and Admin—where the Analyst experience includes Dashboard with client portfolios, Explore all NSE banks, Bank Detail pages with transparent AI Insight Trail, Peer Comparison, Historical Replay, What-If Scenario Analysis, What-If History, and Account management; the CFO experience includes a shared role-aware Dashboard with pending approvals, Insight Summary Detail with Show Basis, Approve/Reject workflow, Approved History, and Account while never exposing raw metrics, formulas, or source_metric_ids; and the Admin experience includes Dashboard, User Management, Client Portfolio Management, Data Source Settings, and Account with no financial insights or AI-generated analysis, implementing role-based routing and redirects, mock authentication using predefined Analyst, CFO, and Admin accounts, React Query hooks, reusable layouts, modular architecture, optimistic updates, loading/error/empty states, accessibility, strong TypeScript typing, scalable folder structure, compliance-first design, transparent AI-generated insights with verifiable source trails, responsive mobile-first UI, and code structured so mock APIs can later be replaced seamlessly with a real backend, delivering a polished, cohesive, enterprise-grade fintech application rather than isolated pages or components.

This project is powered by FinSight Financial Intelligence.

## Overview

FinSight Financial Intelligence provides transparent, auditable AI insights, peer comparisons, historical replay, and scenario modeling for financial consultancy and advisory firms.
